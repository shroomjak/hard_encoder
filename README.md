# hard_encoder
Проект абсолютного энкодера, датчики реализованы на базе STM32 с базовым рабочим ПО при помощи АО "Мостком".

Здесь будет
1. Реализация внешнего интерфейса для получения данных с головки по интерфейсу RS485.
2. Реализация протокола ModBus на основе RS485 для корректной работы нескольких головок, распределения и создания очередности команд, избежания коллизий. Master -- ESP32, slave -- STM32 считывающая головка
3. Проверка самокалибровки и прочих базовых алгоритмов для работы с датчиком угла

## Тесты

```bash
python3 tests/sector_decode_test.py
```

Регрессионный тест декодера сектора: извлекает из `Src/main.c` реальные `calc_sector()`,
`bit_err_corr()` и таблицу `bit_tab[]`, собирает их хостовым `gcc` и проверяет полным
перебором все 144 сектора и все 1296 однобитовых ошибок.
См. [`docs/angle_math_and_calibration.md`, §5.3](docs/angle_math_and_calibration.md#53-два-дефекта-декодирования-и-их-исправление).

### 2. Реализация выходного интерфейса RS485 на STM32
**Электрическая часть** реализована на плате считывающей головки, это готово. USART -> RS485

**Программная часть**: работа с USART, инициализация, настройка, подключение и тест на компьютере через serial monitor через обратное преобразование RS485 -> USART

### 3. Реализация ModBus RTU (RS485)
**Электрическая часть**: печатная плата, параллельная шина портов счтывающих головок (4 шт.), преобразователь RS485 -> USART при подключении к ESP32

Здесь роль Master у ESP32, роли Slave у считывающих головок на STM32.

Шаги реалзации:
1. Найти библиотеку для ModBus RTU на ESP32, разобраться с master
2. Найти то же для STM32, разобраться с slave
3. Настроить связь между ними, подключить одну головку, проверить непрервную работу
4. Тест шины на двух головках

### 4. Тест работы энкодера на вращающемся валу

1. Подключить шаговый двигатель, команды через последовательный порт, реализовано в прошлом курсовом проекте
2. Снять показания через последовательный порт от ESP32 master по всем считывающим головкам
3. Построить диагностические графики (детрендированные показания угла)

### 5. Отработка самокалибровки

Происходит по шине SPI, возможно выполнить внутри IAR изменяя нужные регистры; лучше реализовать внутри ModBus, отдельной командой на самокалибровку конкретной головки
