# Мастер шины RS-485 на ESP32 (`esp32_master`)

Прошивка модуля опроса и оркестрации самокалибровки считывающих головок STM32F722RE по выделенной полудуплексной шине RS-485 (ESP-IDF v5.x). Полная спецификация протокола и регистров приведена в [`../docs/modbus_rtu.md`](../docs/modbus_rtu.md).

## 1. Аппаратное подключение и распределение ядер

| Узел | Параметры |
|---|---|
| `UART2` (RS-485) | `GPIO17 = TX`, `GPIO16 = RX`, `GPIO4 = RTS` (`DE` + `/RE`), `UART_MODE_RS485_HALF_DUPLEX`, `230400 8E1` |
| `UART0` (ПК / консоль) | `921600 8N1`, источник тактирования принудительно переведён на `UART_SCLK_DEFAULT` (`APB = 80 МГц`, `922190` бод, `+0.064%`) |
| Core 0 (`PRO_CPU`) | Задача `encoder_bus` (приоритет `9`) и аппаратный таймер `esp_timer` (`ESP_TIMER_ISR`, `100.000 Гц`) |
| Core 1 (`APP_CPU`) | Задача выдачи `pc_link` (`RINGBUF_TYPE_NOSPLIT`, `64 КБ`) и интерактивная консоль `esp_console` |

## 2. Сборка и прошивка

```bash
cd esp32_master
idf.py set-target esp32
idf.py build
idf.py -p <PORT> flash monitor
```

## 3. Команды консоли (`encoder>`)

После включения мастер находится в `IDLE` и не обращается к шине RS-485 до ввода команды оператором.

| Команда | Описание |
|---|---|
| `scan` | Поочерёдный опрос адресов `1..247` (`FC04` `0x0100..0x0102`, проверка сигнатуры `0xCA01`, длительность `~2.1 с`) |
| `use <id[,id...]>` | Явный выбор рабочих адресов головок (например, `use 1,2` или `use 3`) |
| `poll` | Запуск синхронного опроса `100 Гц` (`SNAP` + чтение `11` регистров `0..10` на каждую головку; для `1..3` головок — `10.000 мс`, для `4` головок — `11.000 мс`) |
| `calib [id[,id...]]` | Запуск 4-этапной самокалибровки выбранных (или указанных в аргументе) головок; опрос `LIVE`-регистров в ходе этапа — `20 Гц` (`50 мс`) |
| `next` | Подтверждение оператора перед началом каждого этапа калибровки и перед переходом к следующей головке |
| `stop` | Остановка `scan`, `poll` или `calib` (в режиме калибровки отправляет `0x0010 STOP` на текущую головку и проверяет `state == 0x00`) |
| `status` | Вывод текущего режима, списка обнаруженных и активных головок |

## 4. Последовательность самокалибровки (`calib`)

Для каждой головки в `esp32_master/main/workflow.c` строго фиксирован порядок этапов:
1. `0x0014` — выравнивание чувствительности фотодиодов `buf_k[6..126]` (`0x70 -> 0x80`), равномерное вращение в любую сторону (`10..40 об/мин`).
2. `0x0013` — поиск оптического центра `offset` (`0x50 -> 0x60`), равномерное вращение в любую сторону (`10..40 об/мин`).
3. `0x0011` — калибровка таблицы секторов `ang_tab` проход 1 (`0x10 -> 0x20`), вращение в сторону **возрастания** угла (`5..20 об/мин`).
4. `0x0012` — калибровка таблицы секторов `ang_tab` проход 2 (`0x30 -> 0x40`), вращение в **противоположную** сторону (`5..20 об/мин`), сохранение в EEPROM и завершающий `0x0010` (`-> 0x00`).

## 5. Формат выходного потока `DATA`

В режиме `poll` каждая итерация `seq` выдаёт в `UART0` одну строку:

```text
DATA seq=<u16> t_us=<u64> snap_us=<u32> poll_us=<u32> error=<mask> id=<id1> ang=<deg|nan> raw_ang=<deg|nan> age_us=<i32> read_us=<u32> gap_us=<u32> ...
```

* `ang` — угол головки в градусах (`6` знаков после запятой), приведённый к общему моменту `t_us` завершения передачи `SNAP`.
* `raw_ang` — исходный угол кадра линейки на момент середины его оптической экспозиции `t_us - age_us`.
* `age_us` — знаковый возраст кадра линейки относительно приёма `SNAP` в микросекундах (`DWT->CYCCNT` головки).
* `error` — битовая маска ошибок по индексу головки в активном списке (`0` — все головки ответили достоверным кадром).
