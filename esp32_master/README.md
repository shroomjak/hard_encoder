# Прошивка ведущего контроллера ESP32

Это **отдельный проект ESP-IDF**. Код в `main/` не прошивается через IAR EWARM: IAR в этом репозитории относится к головке STM32.

Для отладочной платы классической ESP32 с USB-разъёмом (обычно USB↔UART0):

1. Установить ESP-IDF 5.x, открыть терминал с активированным окружением ESP-IDF.
2. Сверить пины UART2/RS485 в `main/bus.c` со схемой платы, адреса головок — в `main/poll_mode.c` (`head_ids[]`) и с `Inc/modbus_board.h` проекта STM32.
3. Подключить плату к компьютеру USB-кабелем **с передачей данных**, затем выполнить:

   ```sh
   cd esp32_master
   idf.py set-target esp32
   idf.py menuconfig      # «Encoder master: режим работы» — выбрать режим (см. ниже)
   idf.py build
   idf.py -p <ПОРТ_ПЛАТЫ> flash monitor
   ```

   Например, вместо `<ПОРТ_ПЛАТЫ>` указать `COM5` (Windows) или `/dev/ttyUSB0` (Linux). Из монитора ESP-IDF выйти сочетанием `Ctrl+]`.

На USB идут **прошивка и журнал** `SNAP/ACK/DATA`. Modbus работает по **отдельным** проводам ESP32 UART2 → преобразователь RS485 → A/B → головки. USB-кабель не заменяет преобразователь RS485. При отсутствии встроенного USB нужен отдельный USB↔UART-адаптер уровня 3,3 В и предусмотренный платой вход в режим загрузчика. Для ESP32-S3/C3 и других моделей сначала проверить целевой чип, доступность UART и распиновку: пример рассчитан на классическую ESP32.

## Два режима прошивки

Режим выбирается **при сборке** в `idf.py menuconfig` → «Encoder master: режим работы».
Файлы каждого режима подключаются в CMake только для него: в рабочей прошивке нет кода,
который шлёт команды калибровки (`CAL_CMD`, `CAL_PAGE`), и наоборот.

| Режим | Файлы | Что делает |
|---|---|---|
| **Рабочий** (`ENCODER_MODE_POLL`, по умолчанию) | `poll_mode.c` | Бесконечный цикл: SNAP(seq) → STATUS(1, 2) → READ(1, 2) только при всех ACK. Поведение то же, что было до разделения. |
| **Калибровка головки** (`ENCODER_MODE_CALIB`) | `calib_mode.c` | Одна головка на адресе `ENCODER_CALIB_SLAVE`: `0x14` → `0x13` → `0x11` → `0x12` → `0x10`, ожидание `STATE` и бита EEPROM, выгрузка `ang_tab` в CSV до и после. Параметры — из `tools/modbus_calib.py`. |

Общая шина (UART2, RS485, 8E1, esp-modbus) — `bus.c`, одна на оба режима.

Параметры режима калибровки (menuconfig, раздел «Encoder master: режим работы»):

| Параметр | По умолчанию | Аналог в утилите |
|---|---|---|
| `ENCODER_CALIB_SLAVE` — адрес головки, 1…247 | 1 | `-s` / `--slave` |
| `ENCODER_CALIB_CONFIRM` — Enter перед каждой командой, `q` + Enter — стоп | да | пауза «Enter — отправить, Ctrl-C — выйти» (без `--yes`) |
| `ENCODER_CALIB_DUMP` — CSV `ang_tab` до и после | да | `dump --table ang_tab` (вручную до запуска) |
| `ENCODER_CALIB_TWICE` — второй круг `0x14`, `0x13` | нет | `--twice` |
| `ENCODER_CALIB_POLL_MS` — период опроса `STATE`, мс (200…5000) | 500 | `--interval` |

Порядок работы в режиме калибровки:

1. Собрать и прошить с режимом «Калибровка головки», выбрать адрес головки.
2. Открыть монитор, дождаться выгрузки `# ang_tab … до калибровки` и сохранить её CSV.
3. Ответить Enter на каждый шаг (или `q` + Enter — стоп с `0x10`). Команды, ожидания и сообщения — как в `docs/calibration_modbus.md`, §3.
4. После `0x10` прошивка выводит выгрузку «после калибровки» и **больше ничего не шлёт** на линию.
5. Для рабочего опроса: `idf.py menuconfig` → «Рабочий режим» → `idf.py flash`.

Таймаут ожидания каждой команды и паузы — из таблицы в `calib_mode.c`. Ожидание бита записи
EEPROM ограничено 60 с (в утилите его не было); при таймауте калибровка прерывается, и
прошивка посылает `0x10`.

Проверка без ESP-IDF (хостовые заглушки и сравнение с утилитой):

```sh
python3 tests/calib_map_test.py
sh tests/host/run_esp32_modes_test.sh
```

Угол передаётся как `uint32` в **микроградусах** (1° = 1000000), старшее 16-битное слово первым, и выводится с шестью знаками после запятой. При переходе с миллиградусов обновлять master и все STM32 slave вместе: автоматического определения масштаба нет. Сборка использует только файлы из `main/CMakeLists.txt`; старый пример `main/encoder_master.c` с другой картой регистров в проект не входит.

Полная инструкция по установке, загрузке, подключению и таблице регистров: [документация Modbus](../docs/modbus_rtu.md#2-как-прошить-esp32-esp-idf-usb-а-не-iar).
